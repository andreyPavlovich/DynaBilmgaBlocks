#  DynaBilmgaBlocks / DBBLOCKS [2005 Client Recreation]🚀

> *"Building physics and blocks together — since 2005 style."*

Welcome to **DBBLOCKS** (formerly inspired by the 2004–2005 *Dynablocks* era), an experimental physics-based sandbox and block-building platform created to emulate the nostalgic charm, blocky aesthetics, and simple Lua/scripting logic of the mid-2000s.

---

##  About the Project
* **Era:** 2005 (Early Alpha / Beta simulation)
* **Engine / Tech:** GODOT / Custom Software Rasterizer (CPP / GAMES 2005 )
* **Core Concept:** Dynamic blocks, basic joint physics, and user-generated mini-games.

##  Features (2005 Edition)
* **Classic Studs & Bricks:** Pure chunky 3D geometry with primary-color palettes.
* **Basic Physics Simulator:** Stacking, tipping, and explosive impulses.
* **Simple Scripting:** Write basic behavior scripts for your dynamic blocks.
* **Retro UI:** Chunky grey-beveled dialogs and Windows XP-era aesthetic.

##  Getting Started🚀
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Open the solution in **Visual Studio 2005** (or compatible era-accurate toolchain).
3. Build the client and run `ROBOBLOCKS-GAME-DBBLOCKS.exe`.
